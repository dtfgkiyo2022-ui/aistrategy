# steel-economy

冶金の文明に入ったら自コアに近い（または資源が多い）区域へ金属ラインを一度頼み、第2時代に入ったら同じ選び方で鋼ラインを一度頼む見本です。戦闘には個別命令を出さず、`maintain` でお任せにします。冶金入りや第2時代入りが遅れたときも、その時点を覚えてから指定秒数だけ待ちます。

`metalDelaySeconds` と `steelDelaySeconds` を変えると、各ラインを頼む時期が変わります。`regionChoice` を `nearCore` にすると自コアに一番近い区域、`resourceRich` にすると区域ごとの資源残量の合計が最も多い区域を選びます。ラインを頼める区域がまだ見えない場合は、見えるまで命令を出さず、同じラインを重ねて頼みません。
## 現在の決まりに合わせた狙いと測定

時計で進む文明・時代を観測してから金属・鋼ラインを一度ずつ頼みます。4試合は `24939負け / 17195勝ち / 24897負け / 17195負け` で全て決着しました。
