# adjutant（副官）

人が直接動かしている部隊を `controlledBy === "Human"` で見つけたら、その部隊には命令を出しません。人が `Focus` で攻めている間は、残りの部隊を自分のコアへ戻し、ホーム拠点を持っていて自分で所有している場合はその拠点を守ります。人が何も攻めていないときは、残りの部隊をコア防衛に回し、内政は `maintain` でお任せにします。

## 人がこう操作すると強い

まず1部隊を選んで人の命令で `Focus` を出し、前線を自分で見ます。その間、副官が他の部隊を守るので、攻めと留守番を分担できます。守備を固くしたいときは守備の優先度を上げ、損害を抑えたいときは許容損害を下げて試してください。拠点を守るよりコアを厚くしたい場合は「ホーム拠点を優先」を切ります。

この見本は答えを固定するものではありません。人がどの部隊をいつ攻めさせるかを変え、残りの部隊の守り方をつまみで試すための出発点です。
