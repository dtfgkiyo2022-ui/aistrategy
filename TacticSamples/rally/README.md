# rally（合図で集結する相棒）

人が戦場のタイミングを決め、戦術は合図された時だけ残りの部隊を動かす見本です。`adjutant` のように人の攻めを読み続けて守るのではなく、平時は守備と兵力温存に徹し、合図を戦術の主な切り替えにします。人が操作中の部隊（`controlledBy === "Human"`）には命令を出しません。

## 遊び方

まず1部隊を人で動かして前線を作ります。敵の位置を見て、地図上の集結地点に `rally`（地点つき）を送り、部隊が集まったら `push` で押し込みます。敵の反撃や別の戦線が気になったら `fallback` で非 Human 部隊をコアへ戻します。合図を出さない時間は、守備命令と `maintain` で資源・兵力を貯めます。

CLIでは次のように合図を送れます。

```powershell
dotnet Headless/Rts.Headless.Cli/bin/Release/net10.0/Rts.Headless.Cli.dll tactic-match --map-seed 1 --terrain --ages --ticks 12000 --west-tactic TacticSamples/rally --east-tactic auto --west-signal "2400:rally@80,0" --west-signal "4800:push" --west-signal "7200:fallback"
```

## 結果

対 `auto`、`--terrain --ages --ticks 12000`、種1〜4を、合図なし・合図ありの各2通りで実行した結果です（10-07 測り直し）。合図ありは、決まった時刻に `2400:rally@80,0` → `4800:push` → `7200:fallback` を送りました。

| 種 | 合図 | 結果 | 決着 | 捨てられた命令 |
|---:|---|---|---:|---:|
| 1 | なし | 未決着 | — | 0 |
| 1 | あり | 負け | 4880 tick・4.1分 | 0 |
| 2 | なし | 負け | 5180 tick・4.3分 | 0 |
| 2 | あり | 負け | 5224 tick・4.4分 | 0 |
| 3 | なし | 未決着 | — | 0 |
| 3 | あり | 負け | 4723 tick・3.9分 | 0 |
| 4 | なし | 未決着 | — | 0 |
| 4 | あり | 未決着 | — | 0 |

**決まった時刻に機械的に合図を送ると、かえって負けやすくなります。** rally は、人が戦況を見て「いま押す」「いま下がる」を判断して合図を押す前提の相棒です。合図の時刻を自動で決めるのではなく、試合の中で人が押してください。

最初の版は、合図がないときの守りの命令に `reservePermille` を付けていて（MaintainReserve 以外では使えない）、すべて捨てられていました。いまは温存率を「損害をどれだけ避けるか」（`allowedLossPermille = 1000 - 温存率`）に置き換えています。
