# ベルト・ラインの道具

内政画面は UI Toolkit の「ベルト」「四角く撤去」「設計図」から使います。すべての操作は既存の `EconomyCommand` を内政の送り口へ送り、表示からシミュレーションを直接変更しません。

- ベルトの物が同じマスに `BeltTicksPerCell` の2倍以上留まると、そのマスが赤く表示されます。建物の `Output` が表示側の容量定数10以上なら「出口が詰まり」、材料を受け取る加工建物の `Input` が0なら「材料待ち」を表示します。
- 建物の一覧には、フレームごとの `Progress` の増加を働いていたフレームとして直近60秒（20 tick/秒）で集計した稼働率を表示します。ベルト終端は、終端セルの物が消えたフレームを到着として数え、直近60秒の個数を「個/分」で表示します。これは表示側の観測値です。
- ベルトは始点から終点までのL字を作ります。通常は横→縦、Shiftを押すと縦→横です。長い道は `EconomyCommand.MaxBeltRun`（256マス）ごとに `PlaceBelt` に分かれます。置く前の下書きは、表示側で分かる範囲の不正を赤くします。
- 「四角く撤去」は範囲内の自軍ベルトと建物だけを数え、「ベルト n・建物 m を撤去」と表示してから、それぞれ `RemoveBelt` / `RemoveBuilding` を送ります。
- 「設計図」では名前を入力して範囲をドラッグし保存します。一覧の「貼り付け」でカーソル下書きを出し、Rで90度回転、クリックで建物の `Place` とベルトの `PlaceBelt` を送ります。地図外や既存物との重なりは赤い下書きになります。削除は一覧の「削除」です。

## JSON

版番号付きの現在版は1です。相対座標の原点は囲んだ範囲の左上で、建物は足跡の左上、ベルトはセル位置を保存します。

```json
{
  "version": 1,
  "name": "精錬ライン",
  "width": 5,
  "height": 3,
  "buildings": [{"kind": 3, "x": 1, "z": 0, "width": 2, "height": 2, "facing": 1}],
  "belts": [{"x": 0, "z": 2, "facing": 0}]
}
```

保存先は `UnityEngine.Application.persistentDataPath/blueprints/*.json` です。
