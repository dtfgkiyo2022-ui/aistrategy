# 設定画面（2026-11-06、オーナー依頼・Claude 設計）

オーナー（11-06、build1106b を見て）：「グラフィックを選択できるようにしたい。今のグラフィックは最低画質で、綺麗なグラフィックも選べるように」「設定画面はどうせ必要なので普通のゲームにあるような設定一式が欲しい」。画質は 4 段階、設定画面には画面・画質の細かい項目・音量・言語を入れる（オーナー回答）。

表示だけの設定で、シミュレーションには一切触れない（決定論に関係しない）。値は `PlayerPrefs` に保存し、次に起動しても残る。

## 1. 開き方
- 画面右上の歯車のボタン、または **Esc**（他に取り消す物（置く建物・地面の指定など）が無いとき）で「メニュー」を開く：**再開／設定／試合をやめてタイトルへ（無ければ試合をやり直す）／ゲームを終了**
- メニューの「設定」で設定画面。設定画面は上にタブ：**画質／画面／音／操作／ゲーム**
- 下に **適用／元に戻す（開いた時の値へ）／既定に戻す（そのタブだけ）／閉じる**。画質・画面は「適用」で反映。音量は動かすとすぐ反映
- 解像度・全画面を変えたら「この表示でよいですか？ 15 秒で元に戻ります」の確認（よくあるゲームと同じ）
- 見た目は今の HUD（UI Toolkit、石と真鍮、docs/ui-toolkit.md）に合わせる。日本語／英語は `UiText.T`

## 2. 画質（4 段階＋細かい項目）
段を選ぶと下の細かい項目がまとめて変わる。細かい項目を1つでも変えると段の表示は「カスタム」。

| 項目 | 低（＝今の見た目） | 中 | 高 | 最高 |
|---|---|---|---|---|
| 影 | ソフト・2048・距離 50・4 段 | ソフト・2048・距離 80 | ソフト・4096・距離 120 | ソフト・4096・距離 180 |
| アンチエイリアス（MSAA） | なし | 2x | 4x | 8x |
| 描画の解像度（render scale） | 1.0 | 1.0 | 1.0 | 1.25 |
| 色の仕上げ（トーンマップ ACES・彩度/コントラストを少し） | なし | あり | あり | あり |
| 光のにじみ（Bloom） | なし | なし | あり（弱） | あり |
| 物の陰り（SSAO） | なし | なし | あり | あり（高品質） |
| 周辺を少し暗く（ビネット） | なし | なし | あり（弱） | あり（弱） |
| 模型の細かさ（LOD bias：遠くまで細かい模型） | 1 | 1.5 | 2 | 3 |
| 模様のにじみ防止（異方性フィルタ） | 切 | 強制オン | 強制オン | 強制オン |
| 森の飾りの木の数 | 600 | 900 | 1200 | 1800 |
| 岩・飾りの数 | 300・360 | 450・540 | 600・720 | 900・1080 |

- **低は今の見た目と1ビットも変えない**（今の URP 設定・カメラ・光のまま）
- 作り方：ProjectSettings（品質レベル）は変えない。低は今の `Assets/Settings/RtsUniversalRenderPipeline.asset` をそのまま使う。中・高・最高は URP の設定を `Assets/Settings/Resources/Graphics/RtsURP_Medium/High/Ultra.asset`（高・最高は SSAO を付けた `RtsUniversalRenderer_HQ.asset` を使う）に置き、実行時に `QualitySettings.renderPipeline` で差し替える（低に戻すときは元の設定に戻す）。中・高・最高の設定ファイルは Editor のメニュー（`RTS/画質の設定を作る`）でスクリプトから作れるようにし、手で作らない。URP の値で実行時に変えられる物（影の距離・MSAA・render scale など）はコードで直接変えてもよいが、低の設定ファイル自体は書き換えない
- 色の仕上げ・Bloom・ビネットは、実行時に作る全体の Volume（コードで `VolumeProfile` を作る）で付ける。カメラの後処理（`renderPostProcessing`）は中以上でオン
- 森・岩・飾りの数は `TerrainVisualLimits` に渡す。変えたら地形の飾りを作り直す（作り直しが重いなら「次の試合から」と表示）
- 細かい項目としては上の表の各行に加え、**FPS の表示**（切/入）も画質タブに置く

## 3. 画面
- 表示モード：全画面（ボーダーレス）／全画面（排他）／ウィンドウ
- 解像度：`Screen.resolutions` から（同じ大きさの重複は除く）。ウィンドウのときは今の大きさも選べる
- 垂直同期：切／入
- FPS の上限：30／60／120／144／無制限（垂直同期が入なら使わない）
- UI の大きさ：80%〜150%（HUD の PanelSettings の倍率。IMGUI の部分も同じ倍率を使えるなら合わせる）
- 明るさ（ガンマ）：-50%〜+50%（後処理の色調整で。低でもこれだけは効かせる）

## 4. 音
- 全体／音楽／効果音／UI の 4 本（今の `GameAudio` の `MasterVolume` などをそのまま使う）。各 0〜100%、ミュートのチェック
- ウィンドウが裏にある時に音を消す：切／入

## 5. 操作
- **キーの割り当てを変えられる**：今ある操作（H＝待っている村人を選ぶ、M＝操作のモード、V＝建物を動かす、Delete＝建物を取り壊す・予約の取り消し、Esc＝取り消し／メニュー、Shift＝選択に足す・ベルトの曲がる順、WASD・矢印＝カメラ）を1か所（`KeyBindings`）にまとめ、各所の `Input.GetKey(KeyCode.X)` をそこ経由にする。重なった割り当ては警告して入れ替える。既定に戻すボタン
- カメラ：移動の速さ（50%〜200%）、ズームの速さ（50%〜200%）、ズームの向きを逆に、画面の端でカメラを動かす（切/入）、端の幅
- ドラッグの判定の距離（今は 8 ピクセル）：4〜20

## 6. ゲーム
- 言語：日本語／English（今の切り替えと同じ値を使う）
- 体力のバー：常に／傷ついた物だけ／選んだ物だけ
- ダメージの数字：入／切
- 操作の説明（ツールチップ）：入／切
- 既定の試合の速さ：x1／x2／x4

## 7. 確かめること
- 低にしたとき、build1106b と同じ見た目（撮影の道具の写真で比べる）
- 段ごとの撮影（`RTS/見た目の写真を撮る` に画質の段を変えて撮る場面を足す）と、製品版で段ごとのフレーム時間（スモークの記録）
- 設定を保存して起動し直すと残る。IL2CPP の製品版で開いて落ちない
