# 見た目の決まり（アートディレクション）

2026-11-06 オーナー決定：**D「卓上のジオラマ」、ぼかしなし**。見本は `D:/rts-art/concept/D2_far.png`（引き）と `D2_near.png`（寄り）。比べた 4 案は同じフォルダの `A_cartoon`・`B_lowpoly`・`C_painterly`・`D_diorama`（オーナーの好み：D → A → C → B）。

この文書は表示（Presentation・UnityHost・素材）だけの決まり。ゲームの判定には一切かかわらない（CLAUDE.md の技術ルール 2・3）。

## 1. ひとことで
「よく塗られた木と樹脂の模型を、明るい昼の光の下で上からのぞく」。形は A（温かい漫画調）、質感と光で模型らしさを出す。**画面の端から端までくっきり**（被写界深度のぼかしは使わない）。

## 2. 決まり

| 項目 | 決まり |
|---|---|
| 形 | 少しずんぐり、角は少し丸める（面取り）。屋根・煙突・炉など、建物の種類ごとに輪郭が違う物を 1 つ持たせる |
| 質感 | 塗った木・樹脂・石の模型。少しのつや（Smoothness 0.25〜0.35 程度）、縁に柔らかい光（リムライト） |
| 光 | 明るい昼。太陽は斜め上（高さ 50°前後）、影は柔らかく短め。物の接地面にほのかな暗さ（AO） |
| 色 | やや明るく、やや鮮やか。地面は黄緑〜土色の落ち着いた色で、建物と兵を目立たせる |
| 陣営の色 | 青・赤をはっきり。屋根・旗・兵の服に陣営の色。地面や資源に陣営の色に近い色を使わない |
| 奥行き | ぼかしの代わりに、画面の奥ほどわずかに明るく・色を薄く（大気のかすみ）。形はくっきり残す |
| 火・煙 | 炉の火は橙の発光、煙は柔らかい白。品の流れが分かる程度に控えめ |
| ベルト | 濃い灰の帯に、進む向きの矢印（陣営の色）。載っている品は種類ごとに色と形を変え、引いても色で分かる |

### 建物の屋根の色（種類の見分け）
陣営の色は旗と屋根の縁に使い、屋根の面は種類の系統で分ける。

| 系統 | 屋根の面 | 例 |
|---|---|---|
| 食料・暮らし | 麦わら・黄土 | 農場、粉ひき、住居 |
| 木 | こげ茶の板 | 林業所、製材所、炭焼き |
| 石・鉱石・金属 | 濃い灰の石 | 採石場、鉱山、精錬所、高炉 |
| 組立・工房 | 赤茶の瓦 | 組立所、歯車工房、ガラス工房 |
| 軍事 | 陣営の色（全面） | 兵舎、射撃場、塔、城 |

## 3. 引いたとき（2600 体を前提に）
- 建物は遠くで軽い版（LOD）に切り替える。軽い版は細部を消し、屋根の色と輪郭だけ残す
- 兵は引くと色の点になる。歩兵・弓兵・騎兵・攻城の見分けは、部隊の頭上の小さな印（旗）で補う
- 面の数の上限（目安）：兵・村人 1 体 800 三角形以下（LOD1 は 200）、建物 2×2 は 15,000 以下（LOD1 は 6,000）、3×3 以上は 25,000 以下（LOD1 は 8,000）
  - 11-06 の農場で確かめた数字。Tripo の出力（約 185 万）を 3,000 まで減らすと作物がトゲトゲに崩れ、6,000 で輪郭は残り、15,000 で元の見た目をほぼ保てた。重さが問題になったら LOD1 の切り替えを早める
- 色はなるべく共通の 1 枚の画像（パレット）にまとめ、まとめて描けるようにする

## 4. 素材の作り方
1. **絵**：GPT Image で、建物 1 種類につき「斜め上 45°・白い背景・影なし」の 1 枚（必要なら正面・横）。地面・質感の模様は Flux（`flux-3-image`）で、継ぎ目のない模様として作る
2. **立体**：Tripo Studio（**プライバシーは非公開**、商用の条件）。FBX か GLB で `D:/rts-art/tripo/<種類>/` に保存
3. **Blender の一括処理**（`Tools/blender/` のスクリプト）：面を上限まで減らす、軽い版を作る、大きさと基準点をマスに合わせる（1 マス＝1 m、建物の底の中心を原点）、向きをそろえる、パレットにまとめる、FBX に書き出す
4. **Unity**：`Assets/RTS/Art/` に置き（Git LFS）、建物の種類ごとの見た目の表に足す。購入素材（`LocalVisualPack`）より優先し、無ければ今の見た目のまま
5. 生成した日・道具・プロンプトを `D:/rts-art/log.md` に記録する（規約の確認・Steam の AI の申告のため）

## 6. 進め方
1. 試し：地面の模様と農場 1 種類を通しで作り、手間・費用・重さを測る
2. 試しの結果を見て、建物を系統ごとに作り直す（食料 → 石・金属 → 工房 → 軍事）
3. 兵・村人は最後（今の購入素材を陣営の色と質感で D に寄せるのが先）
